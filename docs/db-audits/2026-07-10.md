# DB Audit — 2026-07-10 (Phase 0 schema + queries)

**Mode:** STATIC — no live production DB; plan-shape claims not backed by an
`EXPLAIN` are marked *unverified*. Constraint/trigger behavior was verified
live against a local Postgres 17 after fixes were applied.
**Method:** three parallel audit passes (auth/tenancy · planning core +
Phase-2 placeholders · streaming/cost/LLM + pool config), each through the
full lens set (N+1, indexes, query cost, transactions, write patterns,
schema design, lifecycle, tenancy, observability), then merged, verified,
and — per owner instruction — **fixed in the same pass**. Fix status is
recorded per finding below.

## 3. Findings and outcomes

### Critical
- **C1 — SSE cursor event-loss race** (`sse.ts`): global bigserial assigned at insert, visible at commit; poller advancing past a not-yet-committed id permanently drops that event. **FIXED** — per-stream `pg_advisory_xact_lock` in `publishStreamEvent` serializes per-stream commit order; also accepts a `Tx` so 02 §2.3's event+decision-log pair commits atomically (was audit M1). ADR-38.

### High
- **A-H1 — no UNIQUE on member(org, user); duplicate personal orgs reachable** via concurrent heal. **FIXED** — `member_org_user_uidx` (replaces org-only index) + advisory-locked, re-checking `provisionPersonalOrg`.
- **A-H2 — no UNIQUE/index on account(provider_id, account_id)**; OAuth callback unindexed, identity linkable twice. **FIXED** — `account_provider_account_uidx`.
- **B1 — denormalized org_id could disagree with parent's org** (cross-tenant mislabel). **FIXED** — UNIQUE(id, org) on parents + composite FKs on build_specs, decision_log, runs, tasks, messages.
- **C-H1 — no pool error handler**; idle-client drop (routine on Neon) crashes the process. **FIXED** — `pool.on("error")`.
- **C-H2 — pool had no max/timeouts**; exhaustion = infinite queueing, whole-API stall. **FIXED** — max 20, connect 5s, statement 30s, idle-in-tx 30s.

### Medium
- **A-M1 — verification unindexed on identifier** → **FIXED** (idx + expires_at).
- **A-M2 — no TTL purge for session/verification/invitation** → indexes for a future purge **added**; the purge job itself **DEFERRED** to Phase 2 job infra (Temporal) — tracked in ADR-40.
- **A-M3 — stale active-org claim hard-403s a user with other memberships** → **FIXED** — falls through to first-membership heal.
- **B2 — updated_at frozen forever (no $onUpdate)** → **FIXED** everywhere.
- **B3 — build_specs immutability was comment-only** → **FIXED** — BEFORE UPDATE/DELETE trigger (migration 0002); probed live: UPDATE raises.
- **B4 — supersedes self-FK missing vs spec §4.1** → **FIXED**.
- **B5 — meaningless decision_log rows insertable** → **FIXED** — NOT NULL + has-parent CHECK (ADR-39); probed live.
- **B6 — build_specs.session_id unindexed; multiple specs per session possible** → **FIXED** — unique index (one frozen spec per session, 02 §2.1).
- **B7 — inconsistent, undocumented deletion lifecycle** → **DECIDED** — RESTRICT deliberate for v1, ADR-40.
- **C-M2 — no retention for stream_events/cost_events** → **DEFERRED** with explicit triggers: stream_events retention delete when job infra lands (before Phase 1 streaming volume); cost_events partitioning before Phase 2 budget aggregation.
- **C-M3 — cost_events org-only index vs SUM-per-period queries** → **FIXED** — (org, created_at) + run_id indexes.
- **B8/B9 — tasks lacks status/depends_on/acceptance_criteria; messages lacks a replay ordering key** → **DEFERRED BY DESIGN** — Phase 2 placeholders; shape them when the orchestrator lands (don't build 03/Phase-2 scope early). Must-do list: task_status enum + (run_id, status) idx; task_dependencies join table; messages seq bigserial + (run_id, seq) idx; envelope type projection.

### Low (fixed now: cheap)
- **B10** dup-fallback empty window re-threw raw 23505 as 500 → **FIXED** (retry once).
- **C-L2** stream payload unbounded → **FIXED** (64 KB cap; larger artifacts go to S3 by reference).
- **C-L3** SELECT * in SSE poll → **FIXED** (narrow projection).
- **C-L4** zdr_only column vestigial → **FIXED** (asserted at read; refuses zdr_only=false rows).
- **C-L5** per-row seed inserts → **FIXED** (single batch).
- **C-L6** full-page poll throttled by sleep → **FIXED** (drain immediately on 500-row page).
- **A-L1/L3** invitation email idx + pending-unique → **FIXED**.

### Low (deferred, with trigger)
- **B12** (org, user, created_at) index on planning_sessions — add with the Phase 1 session-history endpoint.
- **B13** decision_log intra-transaction ordering — backfill correctly rides stream_events' bigserial; add a seq only if the log is ever read directly for replay.
- **B14** decision_log GIN/trgm text-search index — spec §4.1's own trigger: add only when keyword lookup measurably misses.
- **A-L2** per-request membership lookup → Redis cache when Redis lands.
- **B15** trace_id columns on decision_log/messages/cost_events — decide at Phase 3 (OTel) whether DB-level correlation is wanted.
- **A-M4** personal-org orphan cleanup on user deletion — part of ADR-40's future teardown flow.
- **A-L4/L5** role/status CHECKs on auth tables, missing updated_at on organization/member — cosmetic; Better Auth owns those writes.

### Verified good (no change)
- ADR-29 partial uniques correctly shaped on both tables; optimistic-insert pattern sound.
- (stream_id, id) index is the right key for the poll — org_id deliberately NOT prefixed (a uuid stream is already unique-ish; org stays as defense-in-depth filter).
- `numeric(12,8)` for cost; text ids matching Better Auth; jsonb for the frozen spec blob and heterogeneous envelopes (right call — don't normalize a content-hashed artifact).
- Live routes: no N+1 anywhere; org scoping in every WHERE (foreign-tenant id ≡ missing row).

## 4. Verdict

Schema is now structurally sound for Phase 0/1: tenancy is DB-enforced end
to end (composite FKs close the denormalization seam), business invariants
(one active session/build, one spec per session, one membership per
org+user, one pending invite per address) are constraints rather than
conventions, and the one genuine Critical (SSE event loss) is closed with
a mechanism that also satisfies §2.3's atomicity requirement. Normalization
level is appropriate — the two jsonb blobs are deliberate snapshots, not
laziness, and nothing else is denormalized beyond the ADR-36 org column.
Remaining debt is explicitly triggered (retention jobs, Phase-2 table
shapes, list-endpoint index) rather than silent.

**Re-verified after fixes:** migrations 0001+0002 apply cleanly; signup /
session create / duplicate / SSE stream regression passes; immutability
trigger, member unique, and has-parent CHECK all probed live and rejecting.
`EXPLAIN (ANALYZE, BUFFERS)` pass on the SSE poll and Better Auth lookups
remains open until a seeded live DB exists (Phase 3 verification pass).
